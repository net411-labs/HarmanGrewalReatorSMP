# Harman Grewal social posts

Public image host for Harman Grewal's (REALTOR®, Royal LePage Global Force Realty) scheduled social posts. Metricool pulls each image from its raw GitHub URL.

- `posts/YYYY-MM/`: that month's post images and `captions.md`
- `generator/`: the script that renders the branded 1080×1350 images from a JSON file
